# Conversed Key Private Limited Repository

This repository contains the source code for the **Conversed Key Private Limited** official website.

## 📁 Repository Structure

- `conversed-key/`: The main React + Vite web application.

## 🚀 Quick Start

To view the project:

```bash
cd conversed-key
npm install
npm run dev
```

For detailed information about the features, tech stack, and implementation details, please see the [Project README](./conversed-key/README.md).

## ℹ️ Company Information

**Conversed Key Private Limited** is a premier staffing, recruitment, and BPO outsourcing company.

- **Website**: Built with React, Vite, and Framer Motion.
- **Key Feature**: Fully interactive frontend with integrated WhatsApp communication for all user actions.
