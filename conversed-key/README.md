Conversed Key Private Limited is a premier staffing, recruitment, and BPO outsourcing company dedicated to bridging the gap between forward-thinking organizations and exceptional talent.

## ✨ Features

- **🚀 Interactive Hero Section**: Dynamic typing effects, mouse-parallax backgrounds, and animated particles.
- **📱 One-Click WhatsApp Integration**: All CTA buttons (Get Started, Learn More, Compare, etc.) redirect directly to WhatsApp with pre-filled, context-aware messages.
- **🎯 Smooth Navigation**: Fluid, anchor-based scrolling with proper offsets for a seamless user experience.
- **💎 Premium UI/UX**: Modern glassmorphim design, vibrant gradients, and rich micro-animations using Framer Motion.
- **💼 Comprehensive Job Listings**: Interactive careers section with simple WhatsApp-based application flow.
- **📊 Services Showcase**: Detailed breakdown of Staffing, Recruitment, BPO, and HR solutions with interactive comparison tools.
- **✉️ Dynamic Contact Form**: Frontend-only contact form that captures user details and formats them into a ready-to-send WhatsApp message.

## 🚀 Getting Started

### Prerequisites

- Node.js (v14.0.0 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Rudrakshsachdev/ConversedKey.git
   ```

2. **Navigate to project directory**
   ```bash
   cd conversed-key
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Run development server**
   ```bash
   npm run dev
   ```

## 📱 WhatsApp Integration Logic

Since this is a frontend-centric application, we've implemented a robust "WhatsApp-as-a-Backend" strategy. 

- **Direct Inquiries**: Every "Learn More" button pre-fills the specific service name.
- **Smart Recommendations**: The recommendation quiz generates a message based on the user's business needs.
- **Form Submission**: The contact form captures data and structures it for WhatsApp:
  ```
  *New Contact Form Submission*
  *Name:* John Doe
  *Email:* john@example.com
  *Message:* ...
  ```
